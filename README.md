# React Three Fiber Book Slider

This project demonstrates an interactive book slider created using **React Three Fiber** and **Three.js**. The slider simulates flipping through the pages of a book in 3D space, offering a unique and engaging experience.

## Features

- **3D Book Animation**: A 3D book that flips through pages with smooth animation.
- **React Three Fiber**: Leverages the power of **React Three Fiber** to create interactive 3D elements in React.
- **Customizable**: Easily customizable to fit various use cases, including adding your own pages or changing the animation style.
- **Smooth Transitions**: Fluid page transitions with proper depth and perspective.

Technologies Used
React: Front-end JavaScript framework for building user interfaces.

React Three Fiber: React renderer for Three.js, allowing you to use 3D elements in React.

Three.js: A 3D graphics library that powers the book's 3D environment.
